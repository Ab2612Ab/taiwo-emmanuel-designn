# Taiwo Emmanuel Design

Build a premium, modern, highly polished personal portfolio website for Taiwo Emmanuel Aremu (UI/UX Designer + Web Developer + Product Designer).

Key guidelines & content:
- Strictly a personal portfolio (use "I", "my", "me" — never agency/team/company/we). No fake clients, fake testimonials, fake awards, fake statistics, or fake reviews.
- Aesthetics: warm off-white / light neutral background, near-black primary text, muted dark gray secondary, refined single accent color, editorial typography with strong hierarchy and generous whitespace.
- Navigation: Minimal sticky nav with "TAIWO EMMANUEL", links (Work, About, Services, Contact), availability badge ("● Available for selected projects"), and responsive mobile menu.
- Hero Section: Striking typography ("TAIWO EMMANUEL", roles "UI/UX DESIGNER · WEB DEVELOPER · PRODUCT DESIGNER"), copy "I design digital experiences people understand, enjoy, and remember.", buttons ("VIEW MY WORK", "LET'S WORK TOGETHER"), and a layered UI mockup/browser panel visual placeholder with subtle parallax.
- Selected Work: Showcase 5 projects with distinct visual cards and tags:
  1. TaskFlow (SaaS Project Management Platform)
  2. Banking App (Modern Banking Experience)
  3. E-commerce Platform (E-commerce Shopping Experience)
  4. Healthcare Platform (Healthcare Management Experience)
  5. Analytics Dashboard (Data-driven dashboard experience)
- Routing & Dedicated Case Studies: Fully connect all pages via React Router:
  - / (Home)
  - /work (Full project archive)
  - /about (Personal story, design philosophy, portrait placeholder)
  - /services ("WHAT I DO": UI/UX Design, Web Design, Web Development, Product Design, Creative Development)
  - /contact (Direct links & interactive form: taiwoemmanuel693@gmail.com, WhatsApp https://wa.me/2349045945470, LinkedIn https://www.linkedin.com/in/emmanuel-taiwo-46b309271/, GitHub https://github.com/Ab2612Ab)
  - /work/taskflow
  - /work/banking-app
  - /work/ecommerce
  - /work/healthcare
  - /work/dashboard
- Each case study page must feature: Title, Category, Short Description, The Challenge, My Approach (Research, IA, User Flow, Wireframes, UI Design, Prototype), The Solution, Key Screens mockups, Design Decisions, Responsive Previews, and Next Project navigation.
- "I SPEAK BOTH DESIGN AND CODE" section with two clean columns (Figma, UX Research, Design Systems vs React, JavaScript, HTML, CSS, Git).
- Process section: "FROM IDEA TO INTERFACE" (01 Discover, 02 Define, 03 Design, 04 Build, 05 Refine).
- "CURRENTLY EXPLORING" and Tools sections.
- Contact & Footer: All real links wired up correctly (WhatsApp wa.me link, email mailto, LinkedIn, GitHub).
- High performance, smooth transitions, accessible markup, and fully responsive across mobile, tablet, and desktop.
