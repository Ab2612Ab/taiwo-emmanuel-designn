# Taiwo Emmanuel — Portfolio

Personal portfolio for Taiwo Emmanuel Aremu, UI/UX Designer, Web Developer and Product Designer.

This is a standalone Vite + React application with responsive layouts, project case studies, contact links and a lightweight visual system.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is configured for static deployment on Vercel.
